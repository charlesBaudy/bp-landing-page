# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev      # dev server at localhost:4321
npm run build    # production build to ./dist/
npm run preview  # preview the production build locally
```

No linter or test suite. Use `npm run build` as the validation step after any change — it catches type errors, broken imports, and image processing failures.

## Architecture

**Stack:** Astro 4 (static output) + Tailwind CSS. Deployed on Netlify. No JS framework — all components are `.astro` files with scoped `<style>` blocks and optional `<script>` tags.

**Site:** Landing page for Baudy Peinture, an artisan painter in Toulon (Var, 83). Domain: `baudypeinture.fr`.

### Page routing

```
src/pages/
  index.astro          # Home
  contact.astro
  services.astro
  realisations.astro
  zones/
    toulon.astro
    la-seyne-sur-mer.astro
    six-fours-les-plages.astro
    hyeres.astro
    la-valette-du-var.astro
```

Each zone page is self-contained with city-specific content (no shared data file). All zone pages share the same CSS pattern — changes to one should usually be mirrored to the others.

### Layout

`src/layouts/Layout.astro` is the single shell for every page. It contains:
- All global CSS variables (`--bg`, `--bg-dark`, `--accent`, `--accent-light`, `--primary`, `--text`, `--text-muted`, `--border`, `--card`)
- Global styles including `.reveal` scroll-animation utility, `.page-header`, footer HTML + CSS, font imports (Playfair Display + Plus Jakarta Sans)
- Full Schema.org `LocalBusiness` JSON-LD, Open Graph, Twitter Card, and geo meta tags
- Intersection Observer script for `.reveal` animations

Props: `title`, `description`, `ogImage?` (defaults to `/og-image.jpg`).

### CSS conventions

- No Tailwind utility classes are used in practice — all styling is scoped `<style>` in each `.astro` component.
- Design tokens are CSS custom properties on `:root`, defined in `Layout.astro`.
- Mobile breakpoints: `768px` (primary), `900px` (wide cards/grids), `480px` / `400px` (small phones).
- Section padding pattern: `7rem 0` desktop → `4rem 0` mobile.
- Page header pattern: `9–10rem 0 4–5rem` desktop → `6rem 0 3rem` mobile.

### Images

Real photos live in `src/assets/bp-img/` as `.JPG` and `.jpg` files (HEIC originals deleted). Astro's `<Image>` component from `astro:assets` processes them at build time — they are served as optimised WebP.

The `heic-convert` devDependency was used once to convert originals; it can be ignored going forward.

### SEO / Schema

- Global `LocalBusiness` schema is in `Layout.astro` (telephone, address, areaServed, openingHours, etc.).
- Each zone page injects its own `BreadcrumbList`, city-specific `LocalBusiness`, and `FAQPage` schemas via `<script type="application/ld+json" set:html={JSON.stringify(...)} />`.
- Sitemap generated by `@astrojs/sitemap` with custom priorities in `astro.config.mjs`.
- `public/_redirects` sends all 404s to `/` (Netlify).

### Contact form

The Netlify Forms integration is on the `<form data-netlify="true" name="contact">` in `src/components/Contact.astro`. No backend needed.
